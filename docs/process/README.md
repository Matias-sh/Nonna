# Process Docs

Este directorio contiene el marco operativo para ejecutar prompts del flujo profesional de Nonna.

## Archivos principales

- `prompt-playbook.md`: reglas maestras, dependencias y criterios transversales.
- `prompt-roadmap.md`: estado y orden de ejecucion por bloques.
- `prompt-crosswalk.md`: trazabilidad prompt -> fuente canonica.
- `prompts/`: planes de implementacion detallados por prompt.

## Principio rector

No redisenar la app actual. La estrategia es estandarizar lo que ya funciona con enfoque de Design System senior, de forma incremental y escalable.
