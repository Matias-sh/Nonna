# Prompt Roadmap

## Estado global

- Alcance: prompts 1..19
- Objetivo: estandarizacion profesional sobre app funcional existente
- Estrategia: incremental por feature, sin big-bang

## Orden operativo

1. Fundaciones: 01, 02, 03, 04
2. Biblioteca UI: 05, 06, 07, 08
3. Features + calidad: 09, 10, 11, 12
4. Gobernanza: 13, 14, 15
5. Operacion diaria: 16, 17, 18, 19

## Hitos

- H1: Documentacion base creada (`docs/design-system/*`, `docs/architecture/*`)
- H2: Playbook y planes por prompt guardados en `docs/process/prompts/*`
- H3: Primera ola de implementacion priorizada (03, 04, 05, 09, 10, 11, 12)

## Criterios de avance

- Cada prompt define entradas, salidas, checklist, riesgos y done.
- Cambios ambiguos siempre a `docs/design-system/11-technical-decisions.md`.
- Toda implementacion cruza accesibilidad, performance y testing.
