# Prompt 19 - Preparacion para entrevista

## Objetivo del prompt

Construir narrativa tecnica senior, honesta y defendible usando el trabajo real del proyecto.

## Cuando usarlo

- Preparacion de entrevistas Android/Compose/Design System.
- Cierre de fase de migracion a DS.

## Entradas requeridas

- Estado de arquitectura, DS, calidad y docs del proyecto.
- Trade-offs y decisiones tecnicas reales.

## Salida esperada (archivos a crear/actualizar)

- `docs/interview/design-system-explanation.md`

## Checklist de calidad

- Explica evolucion de pantallas sueltas a sistema.
- Cubre tokens, APIs, MVVM/UDF, a11y, performance, testing, versionado.
- Incluye Q/A clave de entrevista.
- Respuestas defendibles con ejemplos del proyecto.

## Riesgos frecuentes

- Respuestas genericas no conectadas al repo.
- Ocultar trade-offs o limites reales.
- No mostrar criterio de priorizacion tecnica.

## Plan de ejecucion paso a paso

1. Recolectar evidencia de docs y codigo.
2. Redactar narrativa end to end.
3. Preparar respuestas a preguntas frecuentes.
4. Incluir aprendizaje y proximo paso de escala.

## Criterio de done

- Documento util para ensayo tecnico real.

## Dependencias con prompts anteriores

- Requiere evidencia de 01..18.
